<objective>
Migrate the three example apps that construct the class being deleted onto the operation-scoped
pattern (D-19). `apps/*` is in the pnpm workspace and root `pnpm build` runs `turbo build` across
it, so leaving these unmigrated breaks the build the moment plan 15-07 deletes the class — and
`pnpm test` would NOT catch it, because it filters to `./packages/*`. These three files are also
the only place in the repo that demonstrates the concord auth pattern to a reader, so they must
demonstrate the NEW one.

Purpose: this is what makes CAUTH-03's "zero remaining call sites" claim honest repo-wide rather
than scoped around. It also produces the first worked examples of the pattern outside the
package's own internals.

Output: three example files that hold stream signers in a `StreamSigners` instance and answer a
relay's refusal reactively, with every driver, driver-teardown effect, and seen-relays set gone.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Spoofing | each example's `streamSigners.onAuthRequired` | high | mitigate | The handler is the package's own `StreamSigners.onAuthRequired`; the example never hand-rolls an auth loop, so it inherits the "only keys this holder holds, only pubkeys the relay named" property proven in plan 15-01. Examples must not construct their own handler function. |
| T-15-08 | Information disclosure | the previous driver pattern | medium | mitigate | The deleted driver authenticated EVERY held key on every challenge from every relay in the set, so a relay the walk merely touched saw every stream key the example held. Replacing it with `missingPubkeys`-filtered answers narrows what any single relay learns — this is the user-visible half of CAUTH-02. |
| T-15-04 | Tampering (concurrency) | concurrent AUTH for one key | low | accept | D-18 — unchanged. |
| T-15-05 | Denial of service (memory) | walk-local key accumulation | low | accept | D-07 — unchanged; a manual walk holds one community's keys for the page's lifetime by design. |
