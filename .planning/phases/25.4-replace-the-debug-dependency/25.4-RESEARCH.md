# Phase 25.4: Replace the debug Dependency — Research

**Researched:** 2026-09-06
**Requirement:** DEBUG-01
**Confidence:** HIGH

## Recommendation

Implement the workspace's observed logging contract in `packages/core/src/logger.ts` and export its `Debugger` type plus narrowly named test-control functions from `applesauce-core`. Do not add a replacement dependency and do not reproduce `debug` features absent from current call sites.

## Actual Compatibility Surface

Production call sites use a callable `Debugger`, `.extend(segment)`, and `.namespace`. Logger enablement must remain dynamic after construction because module-scope loggers are created before tests or consumers enable namespaces. Existing output requires Node/browser-safe printf handling compatible with `%s`, `%d`, `%o`, `%O`, `%j`, and `%%`, with extra arguments preserved. Namespace matching must support comma/space-separated positive and `-` negative patterns, `*` wildcards spanning `:` segments, and the conventional `DEBUG` environment or browser-storage seed when available.

Only `packages/relay/src/__tests__/debug-capture.ts` and the duplicated helper in `packages/concord/src/helpers/__tests__/relays.test.ts` use the factory-level `enabled`, `enable`, `disable`, and mutable output sink. Replace those test-only imports with explicit core logger controls and consolidate Concord on the relay-style capture discipline where practical. No production call site uses colors, custom formatters, `coerce`, `destroy`, `save/load`, or per-instance log overrides.

Public declarations currently expose `Debugger` through injected logger options and protected/public members in Concord, signers, wallet, and wallet-connect. Define and export the replacement type from `applesauce-core`, then migrate every `import type { Debugger } from "debug"` so emitted declarations no longer require `@types/debug`.

## Package and Lockfile Impact

Runtime `debug` dependencies exist in core, relay, signers, wallet, and Concord. `@types/debug` appears in those packages plus actions, common, and wallet-connect. Remove all manifest entries and regenerate `pnpm-lock.yaml` with the pinned workspace package manager. This phase installs no new package, so the Package Legitimacy Gate is not applicable.

## Verification Strategy

First add core contract tests that independently assert namespace composition/matching, negative patterns, late enable/disable, sink restoration, and formatter behavior. Then migrate relay and Concord capture tests to the new controls and preserve their existing auth/security log assertions. Migrate declaration consumers in package groups and build each affected package. Finish with a repository negative scan for manifest/source references, a frozen lockfile install, affected package builds/tests, and the workspace build/test gate.

## Architectural Responsibility Map

| Responsibility | Owner |
|---|---|
| Logger implementation, public type, namespace state, formatter, sink controls | `applesauce-core` |
| Relay real-output capture and auth/namespace regressions | `applesauce-relay` tests |
| Concord real-output capture and injected logger declarations | `applesauce-concord` |
| Consumer declaration migration | signers, wallet, wallet-connect |
| Dependency removal and lockfile proof | package manifests and root lockfile |

## Risks and Mitigations

- Module-scope loggers can cache a false enable state: compute enablement at each call or update all created instances when patterns change; prove late enablement.
- Formatting drift can invalidate security-sensitive auth log tests: assert hostile `%` and newline values through the actual sink, not a parallel renderer alone.
- Browser bundles can break on `node:util`: implement the small observed formatter without importing Node built-ins in production code.
- Declaration builds can retain `debug` transitively: negative-scan emitted declarations and source imports after all package builds.

## Package Legitimacy Audit

No npm, pip, or cargo package is added. The replacement is repository-owned code and existing dependencies are removed.
