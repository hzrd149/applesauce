# NIP-5D napplet support (GSD quick task)

## Context
NIP-5D ([nips#2303](https://github.com/nostr-protocol/nips/pull/2303)) defines "napplets": sandboxed iframe applets, each published as a manifest event. Applesauce has no support for them yet. The only nsite reference in the repo is a URL inside a test fixture. This task adds the full stack in `packages/common`: helpers, a cast with reactive relationships, operations, a factory, and User cast getters. It also adds a napplet browser example in `apps/examples`.

Spec summary:
- **Kinds**
  - `5129`: snapshot (regular event)
  - `15129`: root napplet (replaceable)
  - `35129`: named napplet (addressable, has a `d` tag)
- **Tags**
  - `x`: exactly one, the lowercase-hex sha256 of `index.html`
  - `z`: archetype, repeatable
  - `i`: intent followed by its parameter names, repeatable
  - `R` / `O`: required and optional NAP domains, repeatable
  - `icon`: sha256 plus a mime type, which must be png, jpeg or webp
  - `server`: Blossom server hint, repeatable
  - `title`, `source`
  - `A` (root address) and `a` (parent address): `5129` snapshots only
- **Content**: a non-empty plain-text description

## 1. Helpers: `packages/common/src/helpers/napplet.ts`
Model the file on `helpers/git-repository.ts` and `helpers/code-snippet.ts`.
- **Constants and types**
  - `NAPPLET_SNAPSHOT_KIND = 5129`, `NAPPLET_ROOT_KIND = 15129`, `NAPPLET_KIND = 35129`, and `NAPPLET_KINDS`
  - A `NappletEvent` type
  - `NappletIntent = { intent: string; params: string[] }`
  - `NappletIcon = { sha256: string; type: "image/png" | "image/jpeg" | "image/webp" }`
- **Validation**: `isValidNapplet(event)` checks four things:
  - the kind is one of the three napplet kinds
  - there is exactly one `x` tag, and it is a 64-character lowercase hex string
  - the content is non-empty
  - a `d` tag is present on 35129 and absent on the other kinds
- **Kind checks**: `isNappletSnapshot`, `isRootNapplet`, `isNamedNapplet`
- **Getters**
  - `getNappletArtifactHash` (`x`), `getNappletDescription` (content), `getNappletTitle`, `getNappletSource`
  - `getNappletServers`, `getNappletArchetypes` (`z`), `getNappletIntents` (`i`)
  - `getNappletRequiredDomains` (`R`), `getNappletOptionalDomains` (`O`)
  - `getNappletIcon`: returns undefined when the hash or mime type is invalid
  - `getNappletParentPointer` (`a`) and `getNappletRootPointer` (`A`): both read only on 5129 events and parse the tag with `getAddressPointerFromATag` from `applesauce-core/helpers/pointers`
- Use `getOrComputeCachedValue` with `Symbol.for(...)` keys for the parsed arrays (intents, domains).
- Export it from `helpers/index.ts`.

## 2. Cast: `packages/common/src/casts/napplet.ts`
`class Napplet extends EventCast<NappletEvent>` covers all three kinds. The constructor checks `isValidNapplet` and throws if the event is invalid.

**Plain getters**
- `artifactHash`, `description`, `title`
- `identifier`: the `d` tag, or undefined
- `archetypes`, `intents`, `requiredDomains`, `optionalDomains`
- `icon`, `servers`, `source`
- `isSnapshot`
- `parentPointer`, `rootPointer`
- `pointer` / `address`, plus `pointer$` / `address$` with outbox relay hints (copy this from `casts/article.ts`). For a 5129 snapshot these use a nevent instead.

**Relationships**: all use `$$ref`, following `casts/note.ts:75-95` and `casts/stream.ts`.
- `comments$`: `CommentsModel` piped through `castTimelineStream(Comment)`
- `reactions$`: `ReactionsModel` piped through `castTimelineStream(Reaction)`
- `zaps$`: `EventZapsModel` piped through `castTimelineStream(Zap)`
- `shares$`: `SharesModel` piped through `castTimelineStream(Share)`
- `snapshots$`: snapshots that derive directly from this napplet. Uses `store.timeline({ kinds:[5129], "#a":[this.coordinate] })`, and is `of([])` when there is no coordinate.
- `lineage$`: every snapshot whose root is this napplet. Uses `"#A":[coordinate]`.
- `parent$` / `upstream$`: for a snapshot, `store.replaceable(parentPointer).pipe(castEventStream(Napplet, store))`, otherwise `of(undefined)`. This follows the pattern in `casts/git-repository.ts`.
- `root$`: the same as `parent$`, but follows the `A` pointer.

**User getters**: augment `User.prototype` with `Object.defineProperty` plus `declare module "applesauce-core/casts"`, the same way `casts/badge-award.ts:43-59` does it.
- `user.napplets$`: the timeline of `{ kinds:[15129, 35129], authors:[pubkey] }`, cast to `Napplet`
- `user.napplet$`: the user's root 15129 napplet, from `store.replaceable`
- `user.nappletSnapshots$`: the timeline of `{ kinds:[5129], authors:[pubkey] }`

Export the cast from `casts/index.ts`.

## 3. Operations: `packages/common/src/operations/napplet.ts`
Every operation goes through `modifyPublicTags` with `setSingletonTag`, `removeSingletonTag`, `addNameValueTag` or `removeNameValueTag`. This follows `operations/git-repository.ts` and `operations/code-snippet.ts`.
- **Single-value fields**
  - `setNappletIdentifier` (uses `includeSingletonTag(["d", …])`)
  - `setNappletArtifactHash`: validates the hex and throws on bad input
  - `setNappletDescription` (uses `setContent`)
  - `setNappletTitle(title | null)`, `setNappletSource(url | null)`
- **Repeatable fields**
  - `addNappletArchetype` / `removeNappletArchetype`
  - `addNappletIntent(intent, params?)` / `removeNappletIntent`
  - `addNappletRequiredDomain` / `removeNappletRequiredDomain`
  - `addNappletOptionalDomain` / `removeNappletOptionalDomain`
  - `addNappletServer` / `removeNappletServer`
- **Icon**: `setNappletIcon(sha256, type) | null`. It throws on an unsupported mime type.
- **Lineage** (snapshots only)
  - `setNappletParent(pointer | address | null)`: the `a` tag, with a relay hint when available
  - `setNappletRoot(pointer | address | null)`: the `A` tag
- Export it from `operations/index.ts` as `export * as Napplet from "./napplet.js"`.

## 4. Factory: `packages/common/src/factories/napplet.ts`
`NappletFactory extends EventFactory<NappletKind, NappletTemplate>`, following `factories/git-repository.ts`.
- **Constructors**
  - `static create(identifier, artifactHash, description)` creates a 35129 named napplet.
  - `static createRoot(artifactHash, description)` creates a 15129 root napplet.
  - `static snapshot(napplet: NostrEvent)` creates a 5129 snapshot.
    - It copies the manifest tags and drops the `d` tag.
    - It sets `a` to the source napplet's coordinate.
    - For `A`, it reuses the source's own `A` when the source is a snapshot. Otherwise `A` is the source's coordinate.
  - `static modify(event)` throws when the event isn't a valid napplet.
- **Fluent methods**, one per operation: `identifier`, `artifact`, `description`, `title`, `source`, `archetype`, `intent`, `requires`, `optional`, `icon`, `server`, `parent`, `root`, and the matching `remove*` methods.
- Export it from `factories/index.ts`.

## 6. Example: `apps/examples/src/examples/napplet/browser.tsx`
Use `examples/torrent/feed.tsx` as the template:
- a `RelayPicker`
- a `pool.subscription({ kinds:[15129, 35129] })` piped into `mapEventsToStore`
- `castTimelineStream(Napplet)`
- `createReactionsLoader` and `createZapsLoader` for the counts

Each row shows the title, description, archetypes, R/O domains and author. Selecting a napplet opens a detail view with its `comments$`, `reactions$`, `zaps$`, and `snapshots$` / `lineage$`. A snapshot's detail view shows links to `parent$` and `root$`.

Styling: plain borders, no shadows, no cards, and no `.form-control`. Add the JSDoc header (`@tags nip-5d, napplet, feed`). Check how `src/examples.ts` discovers examples and register the new one if needed.
