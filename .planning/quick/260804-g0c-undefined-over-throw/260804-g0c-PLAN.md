# Quick Task 260804-g0c: undefined over throw

Findings #1 and #2 from the throw/undefined review. Both are the same defect class
closed in `gift-wrap.ts` at 422ce62b: a getter whose return type already includes
`| undefined` throws on hostile or malformed input instead of returning it.

## Background

`getOrComputeCachedValue` gates on `Reflect.has`, so the memoize-undefined class was
audited separately and came back clean — all 9 mutable-source helpers guard before
caching. This task is only the throw class.

The codebase already recognised the problem and patched it at the **guard** level:
`isHiddenTagsUnlocked`, `isWalletNotificationUnlocked`, `isTokenContentUnlocked` and
`isHistoryContentUnlocked` all open with `// Wrap in try catch to avoid throwing
validation errors`. That leaves direct callers of the public getters exposed and
silently reclassifies a malformed event as "locked" forever. Fixing the source is
what makes the guards unnecessary.

## Task 1 — getHiddenTags (packages/core)

**files:** `packages/core/src/helpers/hidden-tags.ts`

**action:**
- Replace `JSON.parse(content) as string[][]` with `safeParse<string[][]>(content)`
  from `applesauce-core/helpers/json`; return `undefined` when it yields nothing.
- Replace `if (!Array.isArray(parsed)) throw new Error("Content is not an array of tags")`
  with `return undefined`.
- Do NOT cache the rejection — the content is decryptable state and a later correct
  value must still be readable. Return before `setCachedValue`, matching the
  established `if (!tags) return undefined;` pattern in the six hidden getters.
- Update the JSDoc: drop `@throws`, state the undefined contract.
- Remove the now-dead `try {} catch {}` in `isHiddenTagsUnlocked` (line ~71). Its
  param is typed `T extends { kind: number }`, so `HiddenTagsSymbol in event` cannot
  throw, `isHiddenContentUnlocked` does not throw, and `getHiddenTags` no longer does.

**verify:** `npx vitest run packages/core` green; a malformed-content test returns
undefined rather than throwing; revert probe turns the new tests RED.

**done:** `getHiddenTags` has no `throw` and no unguarded `JSON.parse`.

## Task 2 — getWalletNotification (packages/wallet-connect)

**files:** `packages/wallet-connect/src/helpers/notification.ts`

**action:**
- Replace `JSON.parse(content) as WalletNotification` with `safeParse`; return
  `undefined` when it yields nothing, before `setCachedValue`/`notifyEventUpdate`.
- KEEP the `try {} catch {}` in `isWalletNotificationUnlocked` — unlike the
  hidden-tags one it takes `notification: any`, so `WalletNotificationSymbol in
  notification` still throws a TypeError on a primitive. Narrow its comment to say
  what it actually guards now.
- Leave `unlockWalletNotification`'s throw alone: non-optional imperative unlock,
  same split as `unlockSeal`.

**verify:** `npx vitest run packages/wallet-connect` green; malformed notification
content returns undefined; revert probe turns the new test RED.

**done:** `getWalletNotification` has no unguarded `JSON.parse`.
