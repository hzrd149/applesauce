<objective>
Add the `vac` citation to the rekey wire (emit) and the FIRST receive-side `vac` verifier in the codebase (D-08/D-12, ROTATE-08). Today nothing verifies a `vac` on receive (`admin.ts:133` `vacFor` is advisory-only), so a just-demoted admin's rotation is honored by any lagging client off a stale roster (M03).

Purpose: A non-owner rotation must cite its Grant; a receiver verifies that citation against its folded Roster before honoring the rotation, as a second independent access-control gate alongside the existing roster bit-check. Owner exempt. Verification stays a pure function of folded `CommunityState` (D-12 — no live control-plane re-fetch).
Output: `vac` threaded onto the rekey emit path and structurally verified on the receive path.
</objective>
