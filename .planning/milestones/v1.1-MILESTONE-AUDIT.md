### Closed between audit and close (2026-08-02 → 2026-08-04)

Both high-priority todos this audit opened on are resolved. `11-verify-followups.md` is closed
outright and moved to `todos/completed/`; `05.1-review-followups.md` dropped `high` → `low`.

| Item | Was | Now |
|---|---|---|
| **CR-01** — `getGiftWrapSeal` discarded `verifyWrappedEvent`'s boolean, accepting an invalid-signature seal; with the `rumor.pubkey === seal.pubkey` binding against an unverified `seal.pubkey`, an author-spoofing bypass | security BLOCKER | **Fixed** `422ce62b` — gated on `isValidSeal`, which calls `verifyWrappedEvent`. The rationale is recorded in-source: this is the sole insertion point for seals into `internalGiftWrapEvents`, so gating here is what makes that a set of *authenticated* seals |
| **WIRE-02 resurrection** — presence beacons reached `foldMembers`' re-entry branch, so an idle voice client re-added a kicked or departed member; `ban()` worked, `kick()` did not | high, widened by this milestone | **Fixed** `188210bc` — ephemeral kinds excluded from the observed-authors fold |
| **Observed-authors consumer set** — boundary reasoned about in a comment at `client/community.ts:632-639` but unenforced, so a contributor widening `stores.observed` would not be caught | new coverage gap | **Fixed** `b20cde05` — regression test pins the set to `{guestbook, channel:*}` |
| **WR-01** — replaceable version symbol copy | WARNING | **Fixed** `200d9a85` — `copySymbolsToDuplicateEvent` carries a `readonly [symbol, DuplicateSymbolDisposition][]` tuple list. Tuple arity makes adding a symbol without a disposition a compile error, so all six call sites are covered by construction rather than by patching the reachable one |
| **WR-03** — `getSealRumor` undefined sentinel | WARNING | **Fixed** — `isSealUnlocked` value-gated, not presence-only (`gift-wrap.ts:137`) |
| **WR-04** — `EventFactory.kind()` never resolves | WARNING, latent | **Removed** `e829d0a3` — zero call sites, promise never settled; a kind change mid-chain would have dropped preserved symbols anyway |
